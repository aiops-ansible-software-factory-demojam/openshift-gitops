## Recreate on a fresh cluster

With the required CLIs, an AWS account, a valid MaaS key and the AAP subscription
ZIP available, start from the release checkout:

```bash
git clone --branch v0.1.0-alpha.2 --depth 1 \
  https://github.com/aiops-ansible-software-factory-demojam/openshift-gitops.git
cd openshift-gitops
cp .env.demo.example .env
chmod 600 .env
"${EDITOR:-vi}" .env
export KUBECONFIG="$HOME/.kube/config"
oc whoami --show-server
oc whoami
bash bootstrap/bootstrap.sh preflight
bash bootstrap/bootstrap.sh
bash bootstrap/bootstrap.sh webapp mcp-verify
```

Fill `LITELLM_API_KEY`, `AWS_BOOTSTRAP_ACCESS_KEY_ID` and
`AWS_BOOTSTRAP_SECRET_ACCESS_KEY`. Place the subscription ZIP at
`aap_manifest.zip`, or change `AAP_LICENSE_FILE`. Keep all four repository
selectors on the release tag. Remove inherited development overrides from
your shell: nonempty shell values take precedence over `.env`.

The example selects AWS `us-east-2`, the recorded RHEL 9/10 AMIs,
native MCP, and Qwen `qwen38-27b` with thinking disabled for AO and Omnigent.
Bootstrap creates fresh infrastructure and credentials. Verify cluster
identity before running it. See the [main setup guide](../../README.md#set-up-the-cluster)
for prerequisites and the [demo procedure](../../.agents/skills/run-demojam/SKILL.md)
for the outage, independent validation and recovery sequence.

To verify downloaded release assets, run `sha256sum -c SHA256SUMS` in their
directory. Compare `git rev-parse HEAD` with the GitOps commit in the downloaded
manifest. Treat published release tags as immutable.

## Validation and limits

The [2026-10-16 command record](../native-mcp-demo-2026-10-16.md) identifies the
original live bootstrap commits and successful initial investigation,
independent RHEL 9/10 Molecule tests and recovery. Release preparation additionally
tests tag resolution, commit pins, release configuration, native MCP bootstrap
helpers and AWS network derivation. A fresh full bootstrap of this release
has not been run during release preparation.

Repository inputs and the example AMIs are fixed. Operator catalogs, RHUI/RPM
repositories, AWS availability and the hosted model service remain external
inputs; this release does not archive them. The sandbox image is built from
the selected GitOps commit during bootstrap. AMIs must remain accessible in
`us-east-2` to the target AWS account.

Known demo findings remain: Keycloak caps the requested 90-day MCP bearer at
its 10-hour realm session limit, and repeated investigations can hit model
rate limits. The default demo password is `changeme`; use the example's
`DEMO_USER_PASSWORD` field to choose the initial password for new accounts.
